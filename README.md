# Ravindra Singh — Portfolio Website (static HTML version)

Static HTML/CSS copy of the PHP portfolio, ready for **GitHub Pages**.
Open `index.html` directly in a browser to preview — no server needed.

## Structure
```
index.html              ← homepage (all sections)
blog/*.html             ← blog posts
css/style.css           ← styling
images/, assets/        ← images and resume.pdf
```

## Contact form
GitHub Pages can't run PHP or MySQL, so the form posts to
[FormSubmit](https://formsubmit.co), which emails each message to
ravindradeeg95@gmail.com. The first submission sends an activation
email — click the link in it once, and later messages arrive normally.

## Editing
All text is written directly in the HTML files. To add a blog post,
copy a file in `blog/`, edit it, and add a card to the Blog section of `index.html`.
